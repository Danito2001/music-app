# Music App (Tipo Youtube Music)

## Tech Stack
- React
- Next.js
- Redux Toolkit
- TypeScript
- Axios
- Tailwind CSS

## Features
- Reproductor de música completo (play, pause, queue, shuffle, repeat, volumen)
- Sistema de playlists (crear, editar, eliminar y gestionar canciones)
- Búsqueda avanzada por canciones, artistas y álbumes
- Sistema de likes e historial de reproducción
- UI responsive optimizada para mobile y desktop

## Installation

```bash
git clone https://github.com/Danito2001/music-app.git
cd music-app
npm install
npm run dev
